# cb_2024_us_cd119_20m

Static reference data from the US Census Bureau, unlike the other tables in this directory it is checked into git (not regenerated by the pipeline).

## Schema

Standard GeoJSON `FeatureCollection`; each feature represents one of the 435 House districts with Census geographic identifiers (state FIPS, district number) and boundary geometry.

## Notes

- Joined against [congress_members_districts](congress_members_districts.md) by state + district number to render `congress_district_map.html` / `congress_state_map_dual_chamber.html`.
- Source: US Census Bureau cartographic boundary files (public domain), via `us-atlas`/TopoJSON conventions per `README.md`.
