# Democracy Decoded

Knowledge catalog for the `democracy-decoded` project, following the [Open Knowledge Format](https://cloud.google.com/blog/products/data-analytics/how-the-open-knowledge-format-can-improve-data-sharing/) (OKF v0.1).

## Contents

- [tables/](tables/index.md) — generated CSV/GeoJSON data files, their schemas, and provenance
- [concepts/](concepts/index.md) — domain concepts used across the data (generation buckets, bill tracker status, legislative document codes)

## Pipeline

Data flows through four numbered scripts at the repo root (see [`../WORKFLOW.md`](../WORKFLOW.md) for full detail):

1. `1_fetch_member_data.py` → member/generation tables
2. `2_fetch_location_data.py` → adds state/district/chamber
3. `3_create_visualizations.py` → member + map visualizations
4. `4_create_bill_tracker.py` (optional, requires `scripts/congress_bill_fetcher_bulk.py` first) → bill tracker dashboard

All files under `data/` are git-ignored and regenerated by these scripts; the OKF tables here document their schema even when the files themselves aren't present in the working tree.
