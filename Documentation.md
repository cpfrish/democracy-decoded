### U.S. Legislative Document Codes and Citation Prefixes

This table explains the common document types in the U.S. Congress (House and Senate) and the various abbreviations (prefixes) used when citing or searching for specific bills and resolutions.

| **Document Type** | **Prefix** | **Description** | **Example Citation Formats** |
| :--- | :--- | :--- | :--- |
| **House Bill** | House Bill | Full, descriptive name (rarely used for search) | `House Bill 263` |
| | **H.R.** | Standard, official abbreviation for a House of Representatives Bill. | `H.R. 263, 107 H.R. 263, H.R.263, 116H.R.263` |
| | HR | Shortened, common abbreviation. | `HR 263, 107 HR 263, HR263, 116HR263` |
| | H | Minimal, sometimes used in combined searches. | `H263, 116H263` |
| **House Joint Resolution** | H.J. Res. | Official abbreviation for a House measure proposing an amendment to the Constitution or certain non-amendment items. | `H.J. Res. 93, 110 H.J. Res 93, H.J.RES.93, 115H.J.RES.93` |
| | HJRES | Common search abbreviation. | `hjres 93, 110 hjres 93, HJRES93, 115HJRES93` |
| | HJ / HJR | Minimal abbreviations often used for internal systems. | `HJ93, 115HJ93` / `HJR93, 115HJR93` |
| **House Concurrent Resolution** | H. Con. Res. | Official abbreviation for a House measure that requires agreement from both the House and Senate but does not become law (often used for procedural matters or expressing congressional opinion). | `H. Con. Res 31, 116 H. Con. Res 31, H.Con.Res.102, 114H.Con.Res.102` |
| | HCONRES | Common search abbreviation. | `hconres 31, 116 hconres 31, hconres102, 108hconres102` |
| | HCRES / HCR | Alternative abbreviations. | `HCRes102, 114HCRes102` / `HCR102, 114HCR102` |
| **House Resolution** | H. Res. | Official abbreviation for a House measure affecting only the House (e.g., changing House rules or electing officers). | `H. Res. 67, 114 H. Res. 67, H.RES.6, 115H.RES.6` |
| | HRES / HE | Alternative abbreviations. | `hres 67, 114 hres 67, HRES6, 115HRES6` / `HE6, 115HE6` |
| **Senate Bill** | **S.** | Standard, official abbreviation for a Senate Bill. | `S. 1111, 116S.214, S.214` |
| | S | Shorter, common abbreviation. | `S 1111, S214, 116S214` |
| **Senate Joint Resolution** | S.J. Res. | Official abbreviation for a Senate measure proposing an amendment to the Constitution or other specific matters. | `S.J. Res. 42, 103 S.J. Res. 42, S.J.RES.46, 113S.J.RES.46` |
| | SJRES | Common search abbreviation. | `sjres 42, SJRES 42, SJres 42, SJRES46, 113SJRES46` |
| | SJ / SJR | Minimal abbreviations. | `SJ46, 113SJ46` / `SJR46, 113SJR46` |
| **Senate Concurrent Resolution** | S. Con. Res. | Official abbreviation for a Senate measure that requires agreement from both chambers but does not become law. | `S. Con. Res. 55, 112 S. Con. Res 55, S.CON.RES.2, 110S.CON.RES.2` |
| | SCONRES | Common search abbreviation. | `sconres 55, 108 sconres 55, SCONRES2, 115SCONRES2` |
| | SCRES / SCR / SC | Alternative abbreviations. | `SCRES2, 110SCRES2` / `SCR2, 110SCR2` / `SC2, 110SC2` |
| **Senate Resolution** | S. Res. | Official abbreviation for a Senate measure affecting only the Senate. | *Not explicitly listed, but follows the pattern of H. Res.* |

***Note on Citation Examples:*** *The numbers (e.g., `116H.R.263`) often include the **Congress number** (e.g., 116th Congress) directly before the prefix for precise identification.*
